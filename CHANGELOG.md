## 0.1.0

- First distribution from source. Includes adaptive Yumeiro controls, navigation, overlays, a data table with standard and compact variants, 24 theme presets, and the material effect pipeline.
- Text, single-select, checkbox, switch, confirmation multi-select, remote selection, and date and time pickers expose `.form()` entries that return Flutter form fields and accept their state key through `key`. `YumeiroSelectionList.form` and `.multiForm` handle always-visible single and multiple choices. Popup selectors use anchored desktop menus and touch panels. Remote selection includes debouncing and retry, and bounded selection panels build options on demand. The controlled disclosure can keep its form fields mounted while collapsed.
- Inline lists share selection options with fixed selectors and sheets. Selectors carry option details and trigger labels across input modes. Multi-select fields can expose a clear action, remote fields can track dataset changes, and compact windows can recenter a picker when anchor space is limited. The range slider edits both ends of a numeric interval.
- Icon-only actions use `YumeiroButton`. Fixed, menu, and searchable single selections use `YumeiroSelect` with one option type. Vertical segments share the horizontal option model.
- Bottom sheet routes use `YumeiroBottomSheet.show`, `.select`, and `.multiSelect`. Sheets dock in compact portrait touch layouts. `YumeiroFilter.show` opens a dialog on pointer layouts and a sheet on touch layouts, with the same draft, reset, and apply behavior.
- `YumeiroBadge` displays static labels, statuses, and metadata. `YumeiroChip` handles selectable and removable labels. Both share a compact label layout. Callouts and stat tiles use status roles. Read-only and editable ratings round to the same half-star step.
- `YumeiroDataTable` provides a common column model, controlled row selection, configurable row activation, multiple bands, and independent trailing actions. Both variants support `.sliver` for lazy rows. The data table guide includes a server pagination demo with cross-page selection and retry.
- `YumeiroPagination` adds width-adaptive numbered and compact navigation for lists, data tables, and swipeable pages. The compact control opens a direct page jump.
- Date and range pickers share a themed calendar. Time pickers offer direct input and scrollable choices in anchored pointer panels and touch sheets. Range sliders, touch navigation rails, text editing menus, and progress bars follow the active theme.
- Custom themes can resolve built-in role recipes through their fallback chains. Effect and shadow collections are immutable, and built-in effects honor their configured capability tier. Custom surface effects use the direction-aware `paintForeground` hook.
- Integration with Material hosts preserves their theme extensions and supports local language overrides. Preset ID lookup follows registry updates, and unavailable optical shaders resolve to Gaussian blur.
- Dialogs and editors render body content through `child`. Dialogs use `showClose` to control the close button, and `YumeiroDialog.confirm` accepts explanatory text through `message`.
- Dialog and editor dismissal respects form guards. Text-only rows can expose context menus to keyboard users. Local language overrides and disabled menus preserve content state, and Toast acknowledges clipboard writes after completion.
- `YumeiroActionMenu.show` opens an anchored menu for pointer layouts and a titled action sheet for touch layouts. Both use the same action, header, and divider entries. Fixed selection menus reuse lazy option rendering. Toasts use status roles.
- Setting selection, selectable read-only values, panels, detail scaffolds, thumbnails, and media result rows use named entries on their component families. Divider spacing can follow input modality.
- Modality follows the target platform. Narrow pointer windows collapse the sidebar and keep pointer controls. Search shortcuts prioritize the focused pane, and selectable tags expose their selection to assistive technology.
- Selection menus share lazy results and pointer row spacing. Open fixed selectors reflect new options and values, and confirmation multi-select keeps eligible draft edits when choices change. Centered labels reserve equal space for icons on both sides, and remote results follow the field width. Color editing preserves alpha and follows host updates. Artwork shows a bounded loading placeholder in scrollable content, and touch table summaries show the localized empty message.
- Poster grids use one column gap and a dedicated sliver entry. Media cards compose supporting lines and overlay badges. The search toolbar accepts `query` or `controller` in one constructor. Tables omit the selection configuration to disable selection.
- Floating routes preserve local text direction. App localization delegates support host overrides, and theme preset labels use explicit family and variant names.
- Local searchable selects support `.form(searchable: true)`. Searchable selection reports enabled choices and clearing through `onChanged`. An optional `onFreeTextSubmitted` callback handles unmatched text. Dropdowns share option measurement and align to the reading direction. Cascading menus bring new levels into view, and context-menu long presses leave the row's tap action idle.
- Label input and removable chips share rendering. Inline selection lists align the options card with the search field and keep the clear selection control inside its trailing edge. Table hover and touch summaries share row spacing.
- `YumeiroEditor.show` opens a dialog for pointer input and a sheet for touch. Long touch workflows can opt into a full page with `fullscreenOnTouch: true` and set its `pageBackground`. Custom slider theme builders receive the resolved preset parameters. Slider inputs wrap their actions on narrow touch layouts and use `isResetEnabled` to customize reset availability.
- Page headers include a `.compact` entry. `YumeiroTopNavigation.paged` links tabs and swipe pages from one destination list. Setting rows and list tiles share heading styles, and selection rows use `card: true` for the checkbox card appearance. Inline errors use danger callouts.
- Page header search uses the `actions` slot, and empty states take recovery controls through `action`. The search shortcut uses Command+F on macOS and Control+F on other desktop platforms.
