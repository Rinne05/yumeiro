# 组件目录

从 `package:yumeiro/yumeiro.dart` 导入组件，每页的 Dartdoc 链接可查阅完整接口。交互预览运行实际的 Flutter 控件，切到「代码」查看示例。将代码用于自己的项目时，使用[开始使用](/guide/getting-started#运行第一个页面)中的两个导入，并在 `YumeiroApp` 或 `YumeiroScope` 下调用示例函数。

## 控件

- [按钮](./buttons)用于执行明确的命令，涵盖主要、次要、危险和图标操作。
- [文本与标签输入](./inputs)涵盖单行、多行、搜索、表单包装和可编辑标签集合。
- [选择控件](./selection)涵盖内联单选和多选、确认式多选、固定和远程搜索、级联选择、开关、复选框和分段。
- [表单控件](./form-controls)涵盖单选、多选、复选框、开关、远程搜索和折叠区中的日期时间字段。
- [数值与评分](./sliders)涵盖滑块、精确数字输入和可交互的半星评分。
- [颜色选择](./color-picker)支持预设色样、手动编辑和恢复默认色。

## 展示

- [状态与反馈](./display)涵盖徽标、标签、提示、指标和页面状态。
- [媒体](./media)涵盖图片、头像、缩略图、海报网格、媒体卡和结果行。

## 布局与表格

- [页面与容器](./layout)从页面骨架到面板、卡片和滚动视图。
- [列表与设置行](./rows)用于列表入口、配置项、选择行和自适应设置分组。
- [数据表](./data-table)提供标准表头、受控选择、行操作和惰性滚动，示例涵盖触控摘要与服务端分页。
- [紧凑变体](./compact-table)用于需要跨行对齐的内嵌记录，示例对比标准与紧凑外观的多排布局和惰性滚动。

## 导航

- [导航与切页](./navigation)涵盖自适应主导航、顶部标签、滑动页面与页码分页。
- [工具栏和全局搜索](./toolbars)涵盖本页筛选、批量操作和快捷键搜索。

## 浮层

- [对话框和编辑器](./dialogs)用于确认、短交互和需要保留草稿的编辑流程。
- [底部与选择面板](./sheets)涵盖组合筛选的自适应入口，以及动作和选择面板的显式打开方式。
- [上下文菜单与提示](./menus)涵盖右键菜单、长按动作和悬停提示。
- [通知](./toasts)用于短时反馈，以及管理通知的队列和生命周期。

主题、材质和触控适配见[使用指南](/guide/getting-started)。构造器、属性、类型和顶层函数可在 <ApiLink /> 查阅。
